# 会议记录 · ToDo

聊天 / 开会时打开它,**实时记录对话** → **自动区分谁在说话** → 你说一句 **"会议结束"** 自动停止 → App 生成 **Checklist(要点/决议)** 和 **To-Do(待办)**,可一键分享/发给自己。

纯前端 PWA(可装到手机主屏当 App 用),**全部在浏览器本地完成,无需服务器、无需 API key、不上传任何录音**。

## 怎么用

1. 用手机打开 `index.html`(见下方"运行"),把它"添加到主屏幕",就变成一个 App。
2. **声纹登记**:分别按住"录我的声音 / 录对方声音"各说 3~5 秒。两人音色差别越大,自动区分越准。
3. 点 **开始会议**,允许麦克风权限。
4. 正常聊天。文字会实时出现,并自动标注"我 / 对方"。
   - 自动区分模式下,点头像可纠正上一句说错的人。
   - 没登记声纹时为手动模式,点"我/对方"切换当前说话人。
5. 说一句 **"会议结束"**(或点"会议结束"按钮)→ 自动生成小结。
6. 点 **分享 / 发给我**,通过微信/邮件/备忘录等发给自己;也可复制或下载 `.txt`。

历史会议保存在本机(localStorage),可在首页"查看历史记录"里回看。

## 运行

需要通过 `http(s)` 访问(麦克风和 Service Worker 不能用 `file://`)。任选一种:

```bash
# Python
python3 -m http.server 8080

# 或 Node
npx serve .
```

手机和电脑在同一 Wi-Fi 下,手机浏览器访问 `http://<电脑IP>:8080`。
> 注意:手机上麦克风需要安全上下文。`localhost` 可用;局域网 IP 若被浏览器拦截,可用内网穿透/部署到任意支持 HTTPS 的静态托管(GitHub Pages、Vercel、Netlify 等)。

## 浏览器支持

语音识别用的是浏览器内置的 **Web Speech API**:
- ✅ **安卓 Chrome**:支持最好,推荐。
- ⚠️ **iOS Safari**:支持有限、可能不连续。
- 声纹区分用 **Web Audio API**,各主流浏览器可用。

## 工作原理

| 模块 | 文件 | 说明 |
| --- | --- | --- |
| 语音转写 | `js/recognition.js` | 封装 Web Speech API,中文实时转写,断流自动重启保持连续 |
| 声纹区分 | `js/voiceprint.js` | Web Audio 提取基频(自相关)+ 频谱特征,登记两人声纹后按最近邻分类 |
| 要点/待办提炼 | `js/extractor.js` | 规则匹配:行动/承诺词→待办,决议词→要点,并识别时间/截止 |
| 本地存储 | `js/storage.js` | localStorage 保存历史会议 |
| 主流程 | `js/app.js` | 界面、录音、说话人分配、结束触发、结果渲染、分享导出 |

## 已知限制

- **声纹是轻量启发式**,不是深度模型。两人音色接近时会误判;可在会议中点头像纠正,或改用手动模式。
- **转写质量取决于浏览器内置识别**和环境噪声;嘈杂环境效果下降。
- 要点/待办是**关键词规则**提取,信息密度低的闲聊可能提炼不全。若以后想要更聪明的小结,可接入云端大模型(需 API key)再升级 `extractor.js`。
- 录音不落盘、不外传;关闭页面后仅保留文字记录与小结。
